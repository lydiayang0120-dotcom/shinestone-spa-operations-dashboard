## 安全架構

- 公開儲存庫只放程式，不含 PDF、營運數字、存取權杖或密碼。
- Google 登入採 Sheets 唯讀授權；實際存取由來源 Sheet 共用權限決定。
- Google OAuth Client ID 不是密碼，不得加入 Client Secret。
- 資料只存在登入後的瀏覽器記憶體；登出、逾時或讀取失敗時清除，不使用持久化儲存。

## 計算規則

- 新客實績為依預約日期的新客到店數，不使用消費數或客服詢問數。
- 九店固定為中壢、八德、台中、台北、忠孝、板橋、桃園、羅東與青埔岩盤浴。
- 新客實績一律採月報「依預約日期／新客各店消費表」的有到店數。
- 未知新客目標保留空白並顯示「待補」，不得以 0 代替。
- Meta 僅計平台「訊息對話開始次數」，CPA 為訊息花費除以 Meta 詢問數。
- 活動名稱無法明確歸店時保留「品牌整體」，不硬分攤。
- 未知預算與 LAP 實際花費保留空白，不當成 0。
- Meta 與年度預算的同月實際花費不一致時停止顯示。
- 年度預算支援 Meta、Google 關鍵字、Google 多媒體、LAP 品牌私域與 TikTok；TikTok 等階段性投放平台可只建立實際規劃月份，未建立的月份顯示「未規劃」。
- 本機 `file://` 不支援 Google 登入；正式版須使用已授權的 HTTPS 來源。

私人驗收、月報、日誌、帳號清單與數值匯出保存在本機或正式工作中樞，不加入 Git；`data/`、`output/`、`node_modules/` 已由 `.gitignore` 排除。
