# 澤之湯 Shine Stone SPA｜年度營運儀表板 V01

沿用已定稿四頁私人儀表板架構，使用獨立 SS 資料來源與湖水綠視覺。2026 年度區間為 2025/12 至 2026/11。

已將 2025/12–2026/07 月報 PDF 轉為可核對的結構化資料；Meta API 已核對 31 筆 TWD 分店資料，羅東 USD 僅保留原幣備註。2026/08–2026/11 尚無月報，未提供的目標、預算與 Meta 欄位一律保留空白，不以 0 代替。

## 安全架構

- 公開儲存庫只放程式，不含 PDF、營運數字、存取權杖或密碼。
- Google 登入採 Sheets 唯讀授權；實際存取由來源 Sheet 共用權限決定。
- Google OAuth Client ID 不是密碼，不得加入 Client Secret。
- 資料只存在登入後的瀏覽器記憶體；登出、逾時或讀取失敗時清除，不使用持久化儲存。

## 結構與更新

- `dashboard.template.html`：固定湖水綠四頁版型。
- `dashboard-data.js`：十二個月份、九店、新舊客、Meta 與四平台年度預算驗證。
- `dashboard.js`：Google 登入、即時讀取、篩選及每 5 分鐘更新。
- `config.js`：私人 Sheet ID 與公開 OAuth client ID。
- `node build_v02.js`：檢查語法並產生 `index.html`。
- `node --test dashboard.test.js`：只使用合成資料，不含真實營運數字。

## 計算規則

- 新客實績為依預約日期的新客到店數，不使用消費數或客服詢問數。
- 九店固定為中壢、八德、台中、台北、忠孝、板橋、桃園、羅東與青埔岩盤浴。
- 新客實績一律採月報「依預約日期／新客各店消費表」的有到店數。
- 未知新客目標保留空白並顯示「待補」，不得以 0 代替。
- Meta 僅計平台「訊息對話開始次數」，CPA 為訊息花費除以 Meta 詢問數。
- 活動名稱無法明確歸店時保留「品牌整體」，不硬分攤。
- 未知預算與 LAP 實際花費保留空白，不當成 0。
- Meta 與年度預算的同月實際花費不一致時停止顯示。
- 年度預算固定保留 Meta、Google 關鍵字、Google 多媒體與 LAP 品牌私域四平台列；未知數值維持空白。
- 本機 `file://` 不支援 Google 登入；正式版須使用已授權的 HTTPS 來源。

私人驗收、月報、日誌、帳號清單與數值匯出保存在本機或正式工作中樞，不加入 Git；`data/`、`output/`、`node_modules/` 已由 `.gitignore` 排除。
